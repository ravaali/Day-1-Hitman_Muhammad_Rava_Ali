## Dokumentasi Kegiatan

### 1. Rangkuman Materi
- Materi 1: Pengenalan Kurikulum Merdeka & MBKM di Perguruan Tinggi — Kebijakan yang memberikan hak belajar kepada mahasiswa hingga 2 semester (atau hingga 3 semester pada bagian penutup) di luar program studi dengan pengakuan setara 20 SKS per semester
- Materi 2: Program Unggulan MSIB (Magang dan Studi Independen Bersertifikat) — Program kolaborasi dengan mitra industri yang memberikan pengalaman kerja nyata atau pembelajaran kompetensi spesifik selama 1 semester.
- Materi 3: Pengenalan Git & GitHub dalam Pengembangan Perangkat Lunak — Pengenalan sistem version control untuk melacak dan mengelola perubahan kode program menggunakan Git, serta pemanfaatan GitHub sebagai platform penyimpanan repository secara online dan kolaborasi antar pengembang. Materi ini juga mencakup penggunaan AI melalui Prompt Engineering untuk membantu proses pembuatan aplikasi.

### 2. Poin Penting dan Pengetahuan Baru
- Terdapat 8 bentuk kegiatan pembelajaran MBKM yang dapat dipilih mahasiswa, seperti pertukaran pelajar, magang, asistensi mengajar, penelitian, proyek kemanusiaan, wirausaha, proyek independen, hingga membangun desa.
- Berbagai metode pembelajaran modern yang diterapkan meliputi Project-Based Learning (PjBL) berbasis karya nyata, Problem-Based Learning (PBL) pemecahan masalah terbuka, dan Case-Based Learning (CBL) analisis kasus nyata.
- Alur praktis mengikuti program Kampus Merdeka dimulai dari pengecekan data di PDDikti, pembuatan akun di portal resmi, pemilihan program, proses seleksi berkas, hingga pelaksanaan dan konversi SKS.
- Prompt Engineering merupakan teknik menyusun instruksi yang jelas dan spesifik agar AI dapat menghasilkan jawaban atau kode program sesuai kebutuhan.
- Git merupakan sistem version control yang digunakan untuk melacak dan mengelola perubahan kode, sedangkan GitHub merupakan platform online untuk menyimpan repository dan mendukung kolaborasi.

### 3. Pendapat Pribadi tentang Day 1
Menurut saya, materi yang disampaikan pada Day 1 sangat bermanfaat karena memberikan wawasan baru mengenai berbagai kesempatan yang dapat dimanfaatkan mahasiswa selama menjalani perkuliahan melalui program MBKM, khususnya MSIB yang memberikan pengalaman belajar dan kesempatan mengenal dunia kerja secara langsung di industri. Saya juga tertarik dengan pembahasan metode pembelajaran seperti Project-Based Learning, Problem-Based Learning, dan Case-Based Learning karena metode tersebut mendorong mahasiswa untuk lebih aktif dalam membuat proyek, menyelesaikan permasalahan, serta mengembangkan kemampuan berpikir kritis.

Selain itu, materi mengenai Git dan GitHub menjadi pengetahuan baru yang cukup menarik bagi saya, terutama dalam memahami cara mengelola perubahan kode program, menyimpan proyek, dan melakukan kolaborasi dalam pengembangan perangkat lunak. Pengenalan Prompt Engineering juga memberikan pemahaman tentang bagaimana memanfaatkan AI dengan memberikan instruksi yang tepat agar memperoleh hasil sesuai kebutuhan. Secara keseluruhan, materi Day 1 memberikan tambahan pengetahuan yang bermanfaat, baik dalam memahami sistem pembelajaran di perguruan tinggi maupun mengembangkan keterampilan di bidang teknologi.
